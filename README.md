# Race and Roll Demo

The playable web demo of Race and Roll: the Demo Cup (Cow Hills, Magma
Mountain, Valley of the Yamlings, Ridge Runner) with four racers. Built from
the main game's "Web (Demo)" export; this repository only holds the built
files that GitHub Pages serves.

Made with Godot Engine (MIT License). Font: Press Start 2P (SIL Open Font
License 1.1). Licences are listed in the game's Credits.
